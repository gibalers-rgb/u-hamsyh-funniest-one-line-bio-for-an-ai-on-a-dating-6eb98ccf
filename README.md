# Funniest One-Line Bio for an AI on a Dating App

A small deterministic program for the
[make.fun competition](https://make.fun/competitions/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf)
"Funniest One-Line Bio for an AI on a Dating App". It writes a single
one-line bio — at most 180 characters, first-person, with the punch at
the end — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

`OUTPUT_PATH` overrides the output file (default `/output/entry.txt`).
The program uses only the Node standard library, makes no network
calls, and always writes the same text.
